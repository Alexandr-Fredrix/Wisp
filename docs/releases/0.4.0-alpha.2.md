# Wisp 0.4.0-alpha.2

Fix invisible text in the 0.4.0-alpha.1 UI and HUD. Unity 6 could not resolve the privately registered GDI font by family name. Load the embedded TTF through an absolute file path instead. Validate Latin and Cyrillic glyph metrics and atlas material before assigning the font; reject failed candidates and use a validated fallback.

Compilation checked against the installed Unity 6 game. Actual in-game rendering needs a fresh launch. No route, save or input changes in this hotfix.
