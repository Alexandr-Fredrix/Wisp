# Wisp 0.3.0-alpha.2

Удобнее навигация с геймпада и актуальные скриншоты в README.

- Фокус отмечен светлыми уголками, открытые пункты — подчёркиванием; убраны большие залитые выделения.
- Подсказки LB/RB возле вкладок и действия для текущей панели.
- Карта получает левый стик только при фокусе в её панели. Нажатие RS переключает «Справочную» и «Карту сейва».
- Знак ? сохраняется у областей без подтверждённого посещения даже при включённых спойлерах.
- Четыре новых игровых скриншота: маршрут, карта, дневник и настройки.

## Установка

Hollow Knight 1.5.12620 · Windows x64 · BepInEx 5.4.23.5.
Скачай **Wisp-0.3.0-alpha.2.zip** из Assets и распакуй в папку игры. У Wisp один устанавливаемый файл: `BepInEx/plugins/Wisp/Wisp.dll`. BepInEx ставится отдельно один раз. Source code для установки не нужен.

[Скриншоты и описание](https://github.com/Alexandr-Fredrix/Wisp#в-игре) · [Установка](https://github.com/Alexandr-Fredrix/Wisp/blob/v0.3.0-alpha.2/docs/INSTALL.md) · [Сообщить об ошибке](https://github.com/Alexandr-Fredrix/Wisp/issues/new/choose)

**Экспериментальный Pre-release.** Сборка, 37 проверок ядра и 6 Python-тестов прошли. Полный игровой тест управления и сохранения отметок не завершён. Карта сейва может оставаться пустой; переключение типа карты не устраняет причину. Полные справочные карты областей требуют подготовленного кэша; карты врагов загружаются по запросу. У четырёх записей нет карты. Перед обновлением сохрани копию сейвов.
