# Wisp 0.3.0-alpha.1 — Hollow Knight 1.5.12620

Первая тестовая сборка для актуальной игры и BepInEx 5.4.23.5 x64.

- Маршруты 112% и короткой Стальной души, прогресс отдельно для каждого сейва.
- Дневник с портретами врагов и картами мест обитания внутри игры.
- Компактная подсказка и новое оформление.
- Условия до/после заражения Перепутья и подписи карт.
- Перехват игровых кнопок внутри Wisp; перемещение карты стиками и мышью.

Скачайте Wisp-0.3.0-alpha.1.zip. Единственный устанавливаемый файл — BepInEx/plugins/Wisp/Wisp.dll. BepInEx устанавливается отдельно один раз. Source code — для разработчиков.

**Экспериментальная alpha.** Latest означает последний выпуск, не завершённое тестирование. До последних правок проверены: запуск, загрузка тестового слота, импорт отметок, меню, иллюстрированный дневник и возврат в игру на Windows / 2560×1440. Финальное оформление, исправление X, полное прохождение и физическая проверка геймпада ещё не завершены. Сборка и 40 автоматических проверок прошли; они не заменяют игровой тест. Перед установкой сохраните копию сейвов. Карты могут раскрывать неизученные области. У 4 записей нет отдельной карты. Полные региональные карты требуют отдельно подготовленного кэша; карты врагов загружаются по запросу.

Ранняя версия: сообщайте ошибки через Issues, предложения — Discussions. Новые изменения распространяются по personal-use лицензии; ранее выданные MIT-права сохраняются.
