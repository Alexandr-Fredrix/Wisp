# Wisp 0.2.0-alpha.2 — development build

- Keep the shared EventSystem enabled; suspend only menu navigation and pointer input while Wisp is open, and restore them on close/unload.
- Open from gameplay using F8 or both stick buttons. Wisp requests the native game pause and resumes only a pause it created.
- Controller navigation: bumpers switch tabs; directions choose columns/items; A marks a task; B closes; X switches map/filter; right stick scrolls/pans; triggers zoom; Y fits the map.
- Import visited regions from the current save and add 29 milestone rules. Steam account achievements are not imported across saves.
- Context HUD with the next regional task, journal count and kill-counter notifications.
- Centered journal-style window, silver/blue palette, serif text and bounded rows.

The full runtime checklist, particularly physical controller and map validation, remains required before a public binary release.
