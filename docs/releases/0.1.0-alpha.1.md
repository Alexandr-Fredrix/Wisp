# Wisp 0.1.0-alpha.1 — Project foundation

**Предварительный выпуск исходников. Не устанавливаемый мод.**

Документация, MIT-лицензия, C#-структура, проверки репозитория и автоматизация выпусков.

**Source preview only, not a playable release.** No game binaries or third-party artwork are included. Verify the archive with SHA256SUMS.txt.
