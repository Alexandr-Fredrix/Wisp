# Wisp 0.2.0-alpha.3 — development build

- Fixed viewports replace expanding layout groups. Long descriptions scroll within their column.
- Original generated frame and divider, transparent menu rows and subtle selection glow.
- In-game enemy portraits and habitat maps with pan, zoom, multiple maps and expanded view. Images load from the wiki CDN on demand and stay in WispCache; they are not included in release archives.
- The game map remains available; an optional locally prepared region cache provides reference maps, explicitly labelled as full-area spoilers.
- Per-save goal: full 112% guide or a conservative shorter Steel Soul ending route. Goal selection does not change the game's actual mode or erase marks. It does not promise a timed achievement.

Physical Flydigi controller input remains unresolved. A local visual check does not replace the complete release checklist.
