# Wisp 0.2.0-alpha.1 — development build

Реализовано окно на паузе (F8), 22 раздела и 98 шагов, ручные отметки и 23 правила автоматического подтверждения, независимый прогресс сохранений, фильтры и спойлеры. Дневник содержит 164 записи, 163 сопоставления счётчиков и напоминания об изменениях врагов. Портреты и карта области берутся из установленной игры; карта поддерживает масштабирование и перетаскивание.

Target: Hollow Knight 1.5.78.11833 / Modding API v77 / Windows. **Not yet runtime-tested.** Compilation and core tests passed; UI, save round trips, portraits and map rendering require manual validation.

No controller navigation, exact enemy pins, alternative-loaders support or Modlinks listing. No game binaries or extracted artwork are bundled.

See [installation and controls](../INSTALL.md) and [runtime test checklist](../TESTING.md).
