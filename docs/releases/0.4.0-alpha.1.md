# Wisp 0.4.0-alpha.1 — local gameplay candidate

- JetBrainsMono Nerd Font Regular embedded in the DLL; private Windows process registration, no font installation required. The OFL notice is embedded too.
- Shared primary row and context row, distinct active item and controller focus. LB/RB includes Settings and the goal shortcut. D-pad/LT/RT switches detail tabs; A enters content, B returns. Triggers zoom only while controlling a map.
- Journal moves directly from enemy list to habitat/save-map selection; the portrait does not consume a navigation stop.
- The owner's PDF is available as A1–A15, separate B and C routes, and collection references. Existing objective IDs preserve previous manual marks. Long source instructions are reference items, not fabricated automatic completion rules.
- Credits return is explanatory, not a reward or completion checkbox.

Validation: compile against Hollow Knight 1.5.12620/BepInEx 5; core and content tests. Physical controller, actual Unity font rendering, and visual layout still require an in-game check. New PDF locations do not all have cached reference maps. No public release has been published for this candidate.
