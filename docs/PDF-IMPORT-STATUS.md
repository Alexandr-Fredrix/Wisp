# PDF route integration

Source: owner's `Hollow_Knight_63_Achievements_Roadmap_RU.pdf` (27 pages).

`content/route-pdf.json` is the active guide. `route.json` retains legacy objective definitions and region metadata for compatibility.

- A1–A15 source instructions: pages 3–12.
- B: first ending under five hours, then 100% under twenty hours and opposite choices (pages 13–15).
- C: Steel Soul and Steel Heart, no time limit, 100% collection set (pages 15–16).
- Reference collections: pages 17–22. The PDF's original line wrapping is preserved in the scrollable source instructions.
- New explicit tasks include Love Key, Bretta, Shopkeeper's Key, Descending Dark, Shade Soul, Nosk, Oro and the seven dream warriors.
- A9 explains the early White Defender return; A11 explicitly sends the player to trial two for ore before the final nail upgrade. Grey Prince remains after P5. The first ending remains before Void Heart. Opposite choices stay on B.

Do not interpret the counter as proof that every PDF instruction is automatically recognized. Source reference items are deliberately excluded from it; new multi-action instructions have no guessed game flags. Detailed map coverage and a full playthrough are still pending. Missing maps are shown explicitly. This is a gameplay test candidate, not certification of all 63 achievements.
