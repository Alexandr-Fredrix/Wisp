# Changelog

## 1.1.0 — 2026-09-13

- Обновлены три прохождения по редакторским правкам; сохранены ID и существующие отметки.
- Добавлены четыре коллекции: амулеты, гусеницы, осколки маски и черепки сосуда — 111 карточек с картами.
- Убраны скрытые дубли и повторяющиеся справочники; важные задания сохранены.
- Выровнены подписи, стрелки и нижняя навигация; улучшено управление картами.
- Дополнены 29 английских инструкций. Все 15 карт атласа включены для работы без сети.
- Улучшены загрузка/повтор изображений, восстановление отметок, обработка заражения и управление; кэш текстур ограничен 128 МиБ / 24 изображениями.
- README и установка сокращены; внутренние отчёты и планы перенесены в отдельный архив разработки.

English: revised walkthroughs, four Collections categories with 111 cards, duplicate cleanup, aligned navigation, 29 expanded English instructions, 15 offline atlas maps, image retry/progress recovery improvements and a bounded texture cache.

Known limitations: three maps retain Russian image labels; some Journal images require a first download. Native-map destination markers are not implemented. Automated checks pass; a full in-game/controller pass remains pending.
