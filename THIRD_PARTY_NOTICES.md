# Third-party materials

MIT covers original Wisp code and documentation only.

Hollow Knight, its characters, artwork, maps, audio and game assemblies belong to Team Cherry. Game DLLs are not included. Local compilation does not grant redistribution rights.

The community [Modding API](https://github.com/hk-modding/api) is a separate project, not bundled here. Review its terms and each dependency's license before distribution.

The Achievement Path website and its downloaded wiki images are not imported. A source URL alone is not permission to redistribute an image. Before adding third-party assets, record file paths, author, source URL, license/permission, modifications and attribution here.

Do not copy GPL-licensed mod code into MIT-only files without assessing resulting obligations.

Bundled third-party artwork and libraries: **none**.
