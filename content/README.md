# Guide content

route.json contains the original Russian guide adapted from the owner's Achievement Path project: stable chapter/step IDs, descriptions, warnings, spoiler flags and explicit read-only completion rules.

enemies.json contains enemy identifiers, region names, reference links and journal field mappings. Counts come from PlayerData at runtime, not a scraped kill-total table. Shade has no ordinary mapped counter and is deliberately unavailable.

No downloaded website images, maps, fonts, game assemblies or player saves are included. Game portraits/map meshes are read at runtime. Field-existence checks are automated; semantic mapping and gameplay validation are listed in docs/TESTING.md.
