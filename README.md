# Wisp

**Твой проводник по Халлоунесту.**

[English](README.en.md) · [План](docs/ROADMAP.md) · [Выпуски](https://github.com/Alexandr-Fredrix/Wisp/releases) · [Обратная связь](https://github.com/Alexandr-Fredrix/Wisp/issues)

Wisp — разрабатываемый мод-помощник для **Hollow Knight (2017)**: пошаговый маршрут, дневник Охотника и напоминания прямо в игре.

> **Подготовка проекта. Игровой мод пока не готов.** Предварительные выпуски содержат исходники и документацию, не установочный Wisp.dll. Wisp пока отсутствует в Lumafly / Modlinks.

## Планируемые возможности

- Маршрут: куда идти, что сделать и когда задача выполнена.
- Враги области, изображения, карты и остаток убийств для дневника.
- Предупреждения перед важными выборами, настройка спойлеров.
- Прогресс отдельно для каждого сохранения, работа без интернета.
- Управление клавиатурой и контроллером.

Автоматические отметки появятся только для надёжно проверяемых действий. Мод не должен выдавать предметы или принудительно открывать достижения.

## Что готово

Основа C#-проекта, лицензия, правила вклада, шаблоны обращений, проверка репозитория и автоматические предварительные выпуски исходников с SHA-256. Точка входа пока только сообщает о загрузке; совместимость с игрой ещё не проверена.

## Установка и разработка

Не копируй Wisp-source-*.zip в папку Mods: игрового выпуска пока нет. Поддерживаемые версии игры/API и инструкция установки появятся вместе с проверенной сборкой.

Разработка: [DEVELOPMENT.md](docs/DEVELOPMENT.md). Выпуски: [RELEASING.md](docs/RELEASING.md).
