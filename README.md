**Hollow Knight 1.5.12620 · Windows x64 · BepInEx 5 · ранняя версия 0.3.0-alpha.1**

## Что умеет

- Ведёт по шагам: где начать, что сделать и когда задача завершена.
- Читает прогресс текущего сейва; неподтверждаемые действия отмечаются вручную.
- Предлагает цель 112% или сокращённый маршрут Стальной души для каждого сейва.
- Показывает врагов, счётчики дневника и карты мест обитания с приближением и перемещением.

## Установка

1. Один раз установите [BepInEx 5.4.23.5 x64](https://github.com/BepInEx/BepInEx/releases/tag/v5.4.23.5).
2. Скачайте **Wisp-0.3.0-alpha.1.zip** из [Releases](https://github.com/Alexandr-Fredrix/Wisp/releases) и распакуйте в папку игры.
3. Загрузите сейв и нажмите **F8**.

У самого мода **один устанавливаемый файл — Wisp.dll**. Картинки загружаются в кэш при просмотре; исходники скачивать не нужно. [Подробная инструкция](docs/INSTALL.md).

## Что важно знать

Это **экспериментальная alpha**; Latest означает последний выпуск. Запуск и основные окна проверены до последних правок. Финальное оформление, исправление X и физический геймпад ещё проверяются. Перед установкой сделайте копию сейвов. Цель Стальной души не превращает обычный сейв в этот режим. У 4 записей пока нет карты; полные региональные карты требуют подготовленного кэша, карты врагов загружаются автоматически.
