# Wisp

Твой проводник по Халлоунесту — прямо в игре. Автор: **Alex / Alexandr-Fredrix**.

**1.0.0 · Русский / English · Hollow Knight 1.5.12620 · Windows x64 · BepInEx 5.4.23.5**

[Скачать 1.0.0](https://github.com/Alexandr-Fredrix/Wisp/releases/tag/v1.0.0) · [English](README.en.md) · [Сообщить об ошибке](https://github.com/Alexandr-Fredrix/Wisp/issues/new/choose)

Пошаговые маршруты к 112%, достижениям, скоростным концовкам и Стальной душе. Иллюстрации предметов и боссов, карты мест поиска, коллекции и семь встреч с Господином Грибом. Дневник Охотника показывает прогресс записей и позволяет выбрать локацию; атлас открывает региональные карты внутри игры.

Один архив содержит оба языка. В **Настройках** нажмите **Язык: Русский**, чтобы перейти на **English**. Выбор сохраняется отдельно от целей и отметок текущего сейва.

## Установка

1. Один раз установите [BepInEx 5.4.23.5 x64](https://github.com/BepInEx/BepInEx/releases/tag/v5.4.23.5).
2. Скачайте **Wisp-1.0.0.zip** из выпуска и распакуйте в папку игры. Файл мода: `BepInEx/plugins/Wisp/Wisp.dll`.
3. Загрузите сейв и нажмите **F8** или оба стика контроллера.

[Подробная установка и управление](docs/INSTALL.md). Для обновления замените DLL при закрытой игре; отметки сохраняются.

Достижения читаются из игрового профиля, условия шагов — из текущего сейва. Неподтверждаемые действия отмечаются вручную. Выбор цели Стальной души не меняет настоящий режим сейва.

Многие иллюстрации встроены; остальные карты и портреты загружаются с вики при первом просмотре и сохраняются в кэше. Надписи внутри сторонних картинок сохраняют язык оригинала. Английский атлас использует английские карты.

Проверены сборка, содержимое, логика и переключение каталога между языками. Финальный двуязычный интерфейс ещё не проверен в запущенной игре: [точный объём проверок](docs/TESTING.md).
