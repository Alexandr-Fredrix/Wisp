# Участие / Contributing

Ошибки: Issues. Вопросы и идеи: Discussions. Пишите на русском или английском.

Для ошибки укажите версию Wisp и игры, ОС, другие моды и шаги воспроизведения. Не публикуйте сейвы, ключи и личные данные.

Пока принимаются сообщения и предложения. Для вклада кодом сначала согласуйте условия с Alex, чтобы избежать неоднозначного авторства и лицензирования.

Current original changes use the personal-use terms in LICENSE, not an open-source license. Earlier MIT grants remain effective for previously published versions. Do not contribute third-party code or assets without the required rights.
