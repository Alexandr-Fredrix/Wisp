# Wisp

**Your guide through Hallownest.** [Русский](README.md)

A planned companion mod for Hollow Knight (2017): guided routes, Hunter's Journal assistance, location maps and timely in-game reminders.

**Source preview only. No playable release yet.** Current archives contain scaffolding and documentation, not an installable DLL. Wisp is not listed in Lumafly / Modlinks.

Planned: per-save progress, offline operation, spoiler controls and keyboard/controller navigation. Reliable objectives will be detected from game state; ambiguous tasks will retain manual confirmation.

See [development](docs/DEVELOPMENT.md), [roadmap](docs/ROADMAP.md) and [release procedure](docs/RELEASING.md). The initial C# entry point only logs initialization and has not been tested in-game.
